# VideoSeek — 剪辑师的素材搜索引擎

> **给剪辑师的本地素材搜索引擎**：说一句话，1 分钟内从你的视频、图片、文档素材库里找到想要的镜头和配图。全程本地运行，素材不上传。

## 你找素材要多久？

**找素材，是剪辑里最浪费时间、又最没成就感的一步。**

- 你脑子里有画面：「一个穿红裙子的女人站在窗边」「一个胖子在街上走」「海边日落」
- 但你的素材库有几十个文件夹、几万张图片、几百个视频，文件名是 `IMG_0347.jpg`、`素材_最终版_v3.mp4`
- 于是你一个个文件夹翻、一张张图点开看，**半小时过去了，还没找到那张对的图**

**VideoSeek 把这一步压到 1 分钟。**

你直接输入「穿红裙子的女人」「胖的人」「海边日落」，它从你本地的素材库里，直接把对的那张图、那段镜头捞出来。

**一次找素材：从 10–30 分钟 → 约 1 分钟，时间减少九成以上。**

---

## 它是怎么做到的

VideoSeek 不是按文件名搜，而是**理解画面内容**。

| 你输入（人话） | VideoSeek 输出 |
|---------------|---------------|
| 「穿红裙子的女人」 | 直接命中那张图（即使文件名是 `IMG_0347.jpg`） |
| 「胖的人」「浅色衣服」 | 按人物体型、衣服颜色筛选，不依赖文件名 |
| 「海边日落」「会议室白板」 | 语义理解整张画面的内容 |
| 一张截图 | 以图搜图，找到同款构图/同场景的镜头 |

### 替你做掉了这些事

- ❌ 不用**手动给素材打标签**——它自动生成中文描述
- ❌ 不用**记文件名**——你说画面内容就行
- ❌ 不用**挨个文件夹翻**——一个框同时搜视频 + 图片 + 文档
- ❌ 不用**重新索引**——新素材只增量更新，秒级生效
- ❌ 不用**上传素材**——全部在你电脑本地跑，素材一张都不出本机

## 一条流程，两个工具，1 小时 → 10 分钟

VideoSeek 是你**口播剪辑工作流**的前半段：找素材。

配上你自研的**自动剪口播**工具，整条流程是这样的：

```
口播视频粗剪（原来约 1 小时）
  ├─ ① 自动剪气口、去掉重复话语      ← 自研口播工具
  ├─ ② 从本地素材库找配图、找镜头    ← VideoSeek
  └─ ③ 出片
```

| 环节 | 原来 | 现在 |
|------|------|------|
| 剪气口 + 去重复 | 手动一点点抠 | 自动处理 |
| 找配图 / 镜头 | 10–30 分钟 | 约 1 分钟 |
| **一条口播视频总耗时** | **约 1 小时** | **约 10 分钟** |

**每条视频少花 50 分钟，耗时减少约 83%。**

## 谁该用它

- ✅ **剪辑师 / 视频创作者**：素材库越大，越需要它帮你定位素材
- ✅ **做口播、知识付费、课程剪辑的人**：配图找得快，出片就快
- ✅ **有大量本地图片、视频、PDF 的人**：把它当成你自己的「本地谷歌图片」

---

## 核心能力一览

| 能力 | 说明 |
|------|------|
| **视频语义搜索** | 文字描述找镜头，截图搜视频，硬字幕 OCR |
| **图片库** | 图片语义索引 + 自动中文描述 + 人物标签 |
| **文档库（PDF）** | 搜 PDF 里的文字，定位到具体页，连续翻页预览 |
| **统一搜索** | 一个框同时搜视频 + 图片 + 文档 |
| **中文搜图** | 属性筛选 + 文字 + 向量三级路由，中文不再失灵 |
| **纯本地** | ONNX + Lance + FFmpeg，素材不上传 |

## 快速开始

1. 双击 **`install-macos.command`** 装依赖（首次 5–15 分钟）
2. 导入模型（`openai-clip.zip` + `rapidocr-zh-understanding.zip`）
3. 双击 **`run-macos.command`** 启动，添加素材文件夹 → 开始索引 → 搜

完整安装见 [`docs/quickstart.md`](docs/quickstart.md)。
